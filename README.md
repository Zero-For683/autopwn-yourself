# Web security tooling

This is my repo for tool building related to web security. This ranges from vulnerability detection to recon automation.

---

## Vulnerability Detection

**Focus:** Automate vulnerability discovery and exploitation.  
Use Python to build tools that help find and exploit bugs in real web apps.

**Examples:**
- XSS/SSRF/CSRF scanners
- Auth bypass test scripts
- Burp-style PoC generators

---

## Web Enumeration

**Focus:** Automate web reconnosaince using tools already built (nmap, feroxbuster, etc...)
